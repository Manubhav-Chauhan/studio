# **App Name**: assistAI

## Core Features:

- Voice Command Recognition: Enables real-time English speech-to-text for commands and wake word detection, sending transcribed input for AI processing.
- AI Intent & Entity Extraction: Utilizes a generative AI tool to accurately parse transcribed voice commands, determine user intent (e.g., 'open app', 'set volume'), and extract necessary entities for execution.
- Desktop System Command Interface: The Next.js UI component to interact with an underlying desktop agent for executing fundamental system commands such as opening/closing applications and adjusting system volume.
- Smart Bulb Control: Facilitates control over connected smart bulbs through voice commands, acting as a bridge to smart home APIs.
- Command History Display: A dedicated UI panel to display a chronological and searchable history of all voice commands issued and the corresponding actions performed by assistAI.
- Interactive Main Assistant Panel: A central UI element showcasing the assistant's status (listening, processing), live transcription of user speech, and dynamically displaying AI responses or action confirmations.

## Style Guidelines:

- Color scheme: Dark theme, reflecting a modern and sophisticated AI companion for desktop.
- Primary color: A deep, intelligent indigo (#5A28BD), signifying depth and advanced technology, and providing clear contrast with lighter text.
- Background color: A very dark, subtle purplish-gray (#1D1A23), creating an immersive and focused environment for the AI interface.
- Accent color: A vibrant, bright blue (#758AEF) to highlight interactive elements, calls to action, and convey clarity, ensuring excellent visibility against the dark background.
- Headline and body font: 'Inter', a grotesque sans-serif that offers a modern, neutral, and highly readable aesthetic, suitable for both short commands and longer conversational text.
- Utilize clean, abstract line-art icons that subtly communicate their function, avoiding overly literal or busy designs to maintain a sleek, technical appearance.
- Adopt a multi-panel layout featuring a prominent central assistant display flanked by a sidebar for history and settings, optimizing for desktop real estate and logical content organization.
- Incorporate subtle, responsive animations for the animated waveform, listening indicators, and smooth transitions for live transcription, providing immediate and intuitive feedback for voice interactions.
